# گزارش بررسی نسخهٔ 0.1.0

تاریخ محلی بررسی: **۲۰۲۶/۱۰/۱۹ — Asia/Tehran**. محیط: Windows، Node.js 24.18.0. زمان‌های فایل JSON به UTC هستند؛ بنابراین بخشی از اجراها در UTC تاریخ ۲۰۲۶/۱۰/۱۸ دارند.

| بررسی | نتیجه |
|---|---|
| TypeScript strict build | موفق |
| آزمون‌های خودکار بدون شبکه | 43 آزمون؛ 0 شکست |
| همهٔ ۲۶ ابزار از طریق کلاینت رسمی MCP | موفق با داده‌های **مصنوعی** |
| parserها با نمونه‌های رسمی Elsevier | ۸ بررسی موفق؛ این نمونه‌ها دادهٔ زنده نیستند |
| HTTP listener واقعی و پروتکل MCP | موفق |
| stdio واقعی از PowerShell | initialize، فهرست ۲۶ ابزار و فراخوانی موفق |
| موضوعات رسمی Scopus بدون کلید | موفق از HTTP و stdio |
| تشخیص نداشتن کلید | خطای پیکربندی، با data_absence_confirmed=false |
| دسترسی ناشناس به API پروفایل پژوهشگر | HTTP 401؛ شکست احراز هویت، نه نبودن پروفایل |
| دریافت عمومی صفحات پروفایل پژوهشگر/دانشگاه | از محیط ساخت موفق نشد؛ علت، نبودن داده تلقی نشده است |
| دادهٔ زندهٔ پروفایل‌ها با کلید مجاز | **انجام نشده؛ کلید تنظیم نبود** |
| ساخت image Docker | انجام نشده |

آزمون‌ها شامل تفکیک صفر از مقدار گزارش‌نشده، fallback محدود نماهای مجاز، نگه‌داشتن پروفایل موفق هنگام رد نمای شاخص، جلوگیری از ادغام دو هویت حل‌شدهٔ متفاوت، وابستگی تاریخی دانشگاه، مقایسه و batch ناقص، شمارش سالانهٔ کامل query، pagination/cursor، ارجاعات، escape خروجی‌های کتاب‌شناختی، Unicode نام‌ها، cache، صف، quota، timeout و محافظت از کلید/Host/Origin هستند.

اجرای زندهٔ بدون کلید: 2026-10-18T20:52:37.659Z تا 2026-10-18T20:52:38.749Z. passed=true در آن فایل فقط بررسی‌های فهرست‌شده را تأیید می‌کند؛ profile_api_validation برابر not_run_no_key است. هیچ ادعای تأیید زندهٔ پروفایل‌ها یا همهٔ ۲۶ endpoint وجود ندارد.

# گزارش بررسی نسخهٔ 0.2.0

تاریخ: ۲۰۲۶/۱۰/۱۹. محیط محلی Windows / Node.js 24.18.0.

اشکال بازتولیدشده: نام و دانشگاه به فایل Excel نمی‌رسید؛ ابزار یکپارچه وجود نداشت، export_documents فقط متن BibTeX/RIS/CSV می‌داد و مسیر قبلی دریافت مقاله به کلید وابسته بود. آزمون `node --test --test-isolation=none test/author-export.test.mjs` قبل از اصلاح با `Tool export_author_publications not found` شکست خورد و بعد از افزودن ابزار موفق شد. حالت عمومی بدون کلید نیز با سرویس بدون اعتبارنامه جداگانه آزموده شد.

| بررسی | نتیجه |

| TypeScript strict build | موفق |
| آزمون‌های محلی | ۵۴ موفق، صفر شکست، یک آزمون مرورگر اجرا نشده به علت محدودیت محیط |

آزمون‌های مصنوعی، دسترسی به دادهٔ زندهٔ Scopus را ثابت نمی‌کنند. طبق [مستند رسمی Elsevier](https://www.elsevier.support/scopus/answer/scopus-author-profile-faqs)، نمای عمومی برای غیرمشترک فقط ۱۰ مقالهٔ اول و فرادادهٔ محدود را دارد. این نسخه وعدهٔ دریافت همهٔ آثار به‌صورت رایگان نمی‌دهد. اگر بخش Documents شناخته نشود یا چالش دسترسی رخ دهد، خروجی خالی با عنوان «فاقد مقاله» ساخته نمی‌شود.

[گزارش آزمون‌های فعلی](verification/unit-tests.xml). گزارش‌های live-without-key.json، stdio-cli.json، official-contract-checks.json و access-boundaries.json مربوط به بررسی تاریخی نسخهٔ 0.1.0 هستند؛ تأیید مسیر مرورگر جدید محسوب نمی‌شوند.

بازتولید: `npm ci --ignore-scripts` سپس `npm test`. برای آزمون مرورگر روی صفحه‌های مصنوعی، Chromium را نصب کنید و متغیر `RUN_BROWSER_TESTS=1` را تنظیم کنید. برای آزمون زندهٔ بدون کلید، `npm run export:author -- --name "REAL NAME" --university "REAL UNIVERSITY"` را اجرا کنید. هیچ شخص واقعی در آزمون‌های مصنوعی شبیه‌سازی نشده است.

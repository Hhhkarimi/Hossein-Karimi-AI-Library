# سرورهای MCP

این بخش شامل سرورهای قابل اجرای Model Context Protocol برای اتصال ابزارهای هوش مصنوعی به سرویس‌ها و منابع بیرونی است.

## سرورهای موجود

| پروژه | کاربرد | اتصال | راهنما |
|---|---|---|---|
| [Torob MCP](./torob-mcp/) | جست‌وجوی کالا، قیمت و فروشندگان، مشاهدهٔ مشخصات و مقایسهٔ محصولات ترب با ۱۰ ابزار | `stdio` و `Streamable HTTP` | [نصب و استفاده](./torob-mcp/README.md) |

## Torob MCP

پیاده‌سازی مستقل با TypeScript و SDK رسمی MCP است. نسخهٔ محلی به کلید API ترب نیاز ندارد؛ برای استقرار HTTP خارج از دستگاه، تنظیمات احراز هویت در راهنمای پروژه آمده است. ورودی و تنظیمات Cloudflare Workers نیز همراه آن است.

کد منبع، راهنمای فارسی، تنظیمات نمونهٔ اتصال، آزمون‌های خودکار و اسکریپت آزمون زنده در پوشهٔ پروژه قرار دارند. API ترب غیررسمی و مستندنشده است و ممکن است تغییر کند. این پروژه وابسته یا مورد تأیید ترب نیست.

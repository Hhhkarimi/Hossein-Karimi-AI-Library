# NLAI OPAC research notes

Live source checks on 2026-11-14 and 2026-11-15 used public OPAC forms and ordinary anonymous search sessions. Counts are observations at the time of each request. The live verifier repeats the key checks against the catalog.

## Public searches

- The [OPAC home page](https://opac.nlai.ir/opac-prod/homePage.do) links to the [book search](https://opac.nlai.ir/opac-prod/search/searchBF.do). The simple form submits a GET to `search/bibliographicSimpleSearchProcess.do` with `command=I`, `classType=0`, `pageStatus=0`, `attributes.locale=fa`, `simpleSearch.indexFieldId`, `simpleSearch.value`, `simpleSearch.tokenized`, and `bibliographicLimitQueryBuilder.biblioDocType=BF` for books. Its index selector offers general search, title `220885`, creator `220901`, subject `220909`, corporate body `221107`, publication imprint `10070`, publication date `10080`, classification no. `10300`, retrieval no. `10310`, series `220924`, ISSN/ISBN `221091`, article source `10320`, document number `10330`, notes `10340`, other `12730`, GMD `11700`, special collections `12000`, description level `12590`, and donor `12720`. The lower controls in all search modes expose `nliHolding` with blank for all, `holding` for NLAI holdings, `nli` for national bibliography, and `lendable` for lendable holdings.
- The [advanced form](https://opac.nlai.ir/opac-prod/search/bibliographicAdvancedSearch.do?command=NEW_SEARCH&classType=0&pageStatus=1) POSTs to `search/bibliographicAdvancedSearchProcess.do` with `command=I`, `pageStatus=1`, `advancedSearch.simpleSearch[i].{indexFieldId,value,tokenized}` for `i=0..2`, and `advancedSearch.operator[i]` for `i=0..1`. Use the provider’s index ID rather than assuming that an English field name is a request parameter.
- The [multi-field form](https://opac.nlai.ir/opac-prod/search/bibliographicMultifieldSearch.do?command=NEW_SEARCH&classType=0&pageStatus=2) POSTs to `search/bibliographicMultifieldSearchProcess.do`; `command=I`, `classType=0`, `pageStatus=2`, `attributes.locale=fa`, and field keys `indexField[i].id` and `multiFieldSearch.simpleSearch[i].{value,tokenized}`. In order the field IDs are `220885`, `220901`, `220909`, `10070`, `10080`, `10300`, `221091`. Set `multiFieldSearch.operator=0/1/2` for AND/OR/EXCEPT and `multiFieldSearch.downward=false/true` for bottom-to-top/top-to-bottom. A live AND query for `اوتیسم` + `حوزه مشق` + `۱۴۰۴` returned precisely book ID `10027591`. [Captured form logic](https://opac.nlai.ir/opac-prod/js/search/simpleSearch.js)
- The [browse form](https://opac.nlai.ir/opac-prod/search/bibliographicBrowse.do?command=BROWSE_SETUP&classType=0&pageStatus=3) requires initialization with its GET and cookie, and POSTs to `search/bibliographicBrowseProcess.do` with `classType=0`, `pageStatus=3`, `command=BROWSE`, `attributes.locale=fa`, `nliHolding`, `simpleSearch.indexFieldId`, `simpleSearch.value`, and `simpleSearch.tokenized=false`. Live title browse starting at `اوتیسم` returned index terms in `renderer[i].value` with corresponding `renderer[i].indexId` and counts. [Browse form logic](https://opac.nlai.ir/opac-prod/js/search/browse.js)

## Year, print, and identifiers

- Searching the publication date index `10080` for `۱۴۰۴` returned 73,237 results when restricted to holdings, versus 31 when the query used Latin `1404`. An advanced search over the same date index returned 120,327 all, 73,237 holdings, 120,241 national bibliography, and 69,175 lendable. These are search candidate counts. The first holdings page using Persian numerals showed year `۱۴۰۴` in all 15 brief records. The advanced calendar/`from`/`year` equality controls returned zero when combining the known 1404 title term `اوتیسم` with calendar `5` and either digit script, while the advanced clause on `10080` returned dozens of results. [Simple search](https://opac.nlai.ir/opac-prod/search/searchBF.do)
- A record’s public URL is `https://opac.nlai.ir/opac-prod/bibliographic/{id}`. Labeled bibliographic fields are HTML entity-encoded triples of label, colon, and value, with `<br>` between repeated values. The permanent link is present inside `#directLinkPanel`. Return the catalog record ID and the recorded national bibliography number separately. An older record demonstrates the distinction (`941042` vs `م ۷۷-۱۱۳۰۱`). [Old OPAC record](https://opac.nlai.ir/opac-prod/bibliographic/941042)
- Holdings rows give direct evidence for year and print number in fields named `test[i].year` and `test[i].publish`. These two values must match in the same row. `test[i].copy` is a separate number for the physical copy. Records `10027591`, `9928442`, and `10027523` each have displayed holdings containing both year `۱۴۰۴` and print `۱`. `10027591` carries status `فاپا` without a bibliographic printing label. The publisher-supplied record `10288541` has status `فیپا`, a year and ISBN, and zero holdings. A missing print number leaves the printing unverified. [National Library’s first-print selection](https://t.me/s/etelaresaniiran/1289), [Published sample](https://opac.nlai.ir/opac-prod/bibliographic/10027591), [CIP sample](https://opac.nlai.ir/opac-prod/bibliographic/10288541)
- Query `9648618585` in Persian or Latin numerals, hyphenated or bare, matched historical record `759384`. Its bibliographic ISBN field contains the set ISBN and separate volume ISBNs. Mathematically equivalent `9789648618587` matched unrelated record `9928442`. The values converted from current 13-digit listings `9786223878947` and `9789644464294` yielded no 10-digit hits. Treat alternate forms differing only in punctuation or script as formatting variants. The mathematical 10/13 conversion alone cannot establish that two catalog records describe the same work or edition. [ISBN-10 record](https://opac.nlai.ir/opac-prod/bibliographic/759384), [ISBN-13 record](https://opac.nlai.ir/opac-prod/bibliographic/9928442)

## Export, formats, and service limits

- In the same session after a search, the result form `search_BrowseSearchHitsForm` POSTs to `search/briefListSearch.do`. Use `command=SAVE_PRINT`, `selectionRows=2` for selected rows or `1` for the page, `selectionFormat=0` for labeled HTML, `1` for tagged HTML or `5` for ISO 2709 bytes named `selectedRecords.txt`. The form calls format `4` ISO HTML, but it returned the same ISO bytes as `5` with a misleading `.html` attachment suffix. Live ISBN search for `978-622-387-894-7` and export with `renderer[0].checkBox=on`, `classType=0`, `pageStatus=0`, `pageSize=15`, `pageNum=1`, `sortKeyValue1=sortkey_title`, `sortKeyValue2=sortkey_author` yielded a valid 1,713-byte ISO record for ID `10027591`. [Official ISO export help](https://opac.nlai.ir/opac-prod/search/bibliographicSimpleSearch.do?command=isoOnlineHelp), [Official results form logic](https://opac.nlai.ir/opac-prod/js/search/brief.js)
- The library ISO help explains that `فیپا` records are assembled from publisher-supplied preliminary data and later updated after the printed copy is received. It also describes data conversion defects in older imported records and states that current ISO export uses UNIMARC. The record label and observed physical holdings can be returned independently.
- The results summary is `matched count از catalog count`, not page count. The results page exposes sizes 15, 25, 35, and 50. It disables sorting for more than 500 records. Filter progressively with explicit continuation and avoid promising complete catalog coverage from a bounded request. [Results form logic](https://opac.nlai.ir/opac-prod/js/search/brief.js)
- NLAI’s project director reported Z39.50 access to the national bibliography in 2017–2019. A current public host, port, and database identifier remain unverified. The NLAI/IFLA paper’s `.rdf` route applies to authority records. [NLAI Libtech report](https://www.researchgate.net/publication/344458621_Implementing_the_Libtech_Open_Innovation_Platform_in_National_Library_and_Archives_of_Iran_NLAI), [IFLA NLAI thesaurus paper](https://library.ifla.org/2091/1/113-akbari-daryan-en.pdf)

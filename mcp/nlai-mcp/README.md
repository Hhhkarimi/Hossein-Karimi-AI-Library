# MCP کتابخانهٔ ملی ایران

سرور محلی برای جست‌وجو و استخراج فرادادهٔ زنده از فهرست عمومی سازمان اسناد و کتابخانهٔ ملی ایران. ۱۵ ابزار برای جست‌وجوی پیشرفته، مرور نمایه، شابک، شمارهٔ کتاب‌شناسی ملی، وضعیت فیپا و فاپا، بررسی چاپ اول و دریافت فایل. پیاده‌سازی TypeScript با SDK رسمی MCP، اتصال `stdio` و Streamable HTTP محلی، مطابق ساختار FutureTools و Scopus در کتابخانهٔ هوش مصنوعی حسین کریمی. [فهرست عمومی کتابخانه](https://opac.nlai.ir/opac-prod/homePage.do) · [مخزن الگو](https://github.com/Hhhkarimi/Hossein-Karimi-AI-Library)

## نصب و اتصال

پیش‌نیاز Node.js 24 و دسترسی به `https://opac.nlai.ir` است. خواندن این صفحات عمومی به کلید API، حساب کاربری یا مرورگر نیاز ندارد. مخزن را دریافت کنید و در پوشهٔ MCP کتابخانهٔ ملی این دستورها را اجرا کنید.

</div>

```sh
git clone https://github.com/Hhhkarimi/Hossein-Karimi-AI-Library.git
cd Hossein-Karimi-AI-Library/mcp/nlai-mcp
npm ci --ignore-scripts
npm run build
npm test
```

<div dir="rtl">

در PowerShell اگر اجرای `npm.ps1` محدود است، `npm.cmd` را به‌کار ببرید. در کلاینت MCP برای `stdio` مسیر مطلق `dist/stdio.js` را تنظیم کنید. مثال زیر را با مسیر محل نصب جایگزین کنید.

</div>

```json
{
  "mcpServers": {
    "nlai": {
      "command": "node",
      "args": ["C:/path/to/nlai-mcp/dist/stdio.js"],
      "env": {"NLAI_EXPORT_DIR": "C:/path/to/nlai-exports"}
    }
  }
}
```

<div dir="rtl">

برای HTTP محلی `npm run start:http` را اجرا کنید. نشانی اتصال `http://127.0.0.1:8793/mcp` است و `/health` سلامت فرایند را نشان می‌دهد. متغیر `PORT` شمارهٔ درگاه را تغییر می‌دهد. HTTP روی loopback می‌ماند. فایل‌های HTTP تا یک ساعت در حافظه در دسترس‌اند. هر دو اتصال فایل را با `resource_link` هم ارائه می‌کنند. در `stdio` فایل در `NLAI_EXPORT_DIR` یا پوشهٔ `exports` نسبت به مسیر کاری فرایند ذخیره می‌شود.

## نمونهٔ جست‌وجو

شرط اول عنوان را جست‌وجو می‌کند. شرط دوم ناشر را در نمایهٔ مشخصات نشر پیدا می‌کند و شرط سوم سال را در نمایهٔ تاریخ نشر می‌سنجد.

</div>

```json
{
  "name": "search_books",
  "arguments": {
    "query": {
      "clauses": [
        {"field": "title", "value": "اوتیسم"},
        {"field": "publication", "value": "حوزه مشق", "join": "and"},
        {"field": "publication_date", "value": "۱۴۰۴", "join": "and"}
      ]
    },
    "page": 1,
    "page_size": 15
  }
}
```

<div dir="rtl">

برای سالِ تنها، `query.publication_date.from` را بدهید. برای سال‌های شمسی، برنامه رقم‌های آن را فارسی می‌کند. فیلد `publication_date` در `clauses` مقدار ورودی را مستقیم به نمایه می‌دهد. برای بازه یا مقایسهٔ سال، حداقل یک شرط متنی بدهید و از `query.publication_date` با `operator` برابر `between`، `gt`، `lt` یا `eq` استفاده کنید. گزینه‌های تقویم طبق فرم ارسال می‌شوند. آزمون زندهٔ تاریخ شمسی با انتخاب صریح تقویم جلالی و بدون آن نتایج متفاوتی داد. برای سال مشخص شمسی، مسیر نمایهٔ تاریخ نشر با ارقام فارسی آزموده شده است. [فرم پیشرفته](https://opac.nlai.ir/opac-prod/search/bibliographicAdvancedSearch.do?command=NEW_SEARCH&classType=0&pageStatus=1)

نام فیلدهای جست‌وجو شامل `all`، `title`، `creator`، `subject`، `corporate_body`، `publication`، `publication_date`، `classification`، `call_number`، `series`، `isbn_issn`، `article_source`، `document_number`، `note`، `other`، `material_designation`، `special_collection`، `description_level` و `donor` است. `match` مقدار `words` یا `exact` می‌گیرد. `join` از شرط دوم به بعد `and`، `or` یا `except` است. برای زبان فارسی از `query.language: "per"` و برای اطلاعات مقدماتی فیپا از `query.cataloging: "fipa"` استفاده کنید.

نوع ماده پیش‌فرض `book` است. ابزار جست‌وجو برای منابع دیگر `material` را هم می‌گیرد. فیلتر پایگاه `database` یکی از `all`، `holdings`، `national_bibliography` و `lendable` است. اندازهٔ صفحه ۱۵، ۲۵، ۳۵ یا ۵۰ و ادامه از `next_page` است. `sort` و `secondary_sort` شامل عنوان، پدیدآور، ناشر، سال و محل نشر، دو رده‌بندی، شناسهٔ بازیابی، موضوع و شمارهٔ مدرک‌اند. خود فهرست مرتب‌سازی را برای بیش از ۵۰۰ نتیجه غیرفعال می‌کند.

## چاپ اول در یک سال شمسی

</div>

```json
{
  "name": "find_first_printings",
  "arguments": {
    "year": "۱۴۰۴",
    "database": "holdings",
    "include_unverified": true,
    "scan_limit": 15
  }
}
```

<div dir="rtl">

ابزار سال را در نمایهٔ تاریخ نشر جست‌وجو می‌کند. برای تأیید، یک سطرِ جدول نسخه‌ها باید هم سال درخواستی و هم نوبت چاپ ۱ را داشته باشد. شاهد در `matching_holdings` با پیوند رکورد آمده است. فیلد `copy` شمارهٔ نسخهٔ فیزیکی است. حالت `unverified` یعنی شاهد کافی در نمای عمومی پیدا نشده است. ترجمه‌ها، جلدها و چاپ‌های ناشران مختلف با شناسهٔ خودشان باقی می‌مانند.

`candidate_total` شمارش نامزدهای فهرست، `confirmed_count` تعداد چاپ‌اول‌های احرازشده در همین فراخوانی و `next` موقعیت ادامه است. برای گرفتن فایل همین نوبت، همین ورودی را به `export_first_printings` بدهید و `format` را انتخاب کنید. بررسی کامل همهٔ نامزدهای یک سال به خواندن جزئیات همهٔ صفحه‌ها نیاز دارد. کتاب‌هایی ممکن است شاهد چاپ را در نمای عمومی نداشته باشند یا در نمایهٔ سال نامزد نشوند. [نمونهٔ دارای شاهد چاپ](https://opac.nlai.ir/opac-prod/bibliographic/10027591)

برای استخراج طولانی و قابل‌ادامه، دستور زیر هر بار تا ۱۰ بخش می‌خواند. اجرای مجدد همان دستور در همان پوشه از بخش بعدی شروع می‌کند. پارامتر `--max-batches` تعداد بخش‌های اجرای جاری را تغییر می‌دهد. هر بخش حداکثر ۵۰ نامزد دارد. `--query` یک JSON اختیاری با `database`، `language` و تا دو شرط `clauses` با «و» می‌گیرد.

</div>

```sh
npm run harvest:year -- --year 1404 --out ./first-printings-1404 --max-batches 10
```

<div dir="rtl">

فایل `first-printings.jsonl` شناسه‌های تأییدشدهٔ یکتا را دارد. `summary.json` پوشش و موقعیت ادامه را نگه می‌دارد. فایل‌های `batches/` شاهد و خطاها را برای بازبینی حفظ می‌کنند. خطای موقت در خواندن سایت، ادامه را در همان بخش نگه می‌دارد. فهرست زنده است و ترتیب یا شمارش نامزدها ممکن است میان اجراها تغییر کند. برابر ماندن شمارش به معنی ثابت ماندن ترتیب رکوردها نیست.

## شابک، فیپا و خروجی

`lookup_isbn` شابک‌های دارای خط‌تیره یا رقم فارسی، عربی و لاتین را می‌پذیرد. گزینهٔ `try_equivalent_forms` تبدیل ۱۰/۱۳رقمی را جداگانه جست‌وجو و با برچسب مشخص برمی‌گرداند. شمارهٔ OPAC، شمارهٔ کتاب‌شناسی ملی و کد پیگیری سه فیلد جدا هستند. `get_book` وضعیت خام و `cataloging_kind` را برمی‌گرداند. `fipa` دادهٔ مقدماتیِ پیش از انتشار و `fapa` برچسب مستقل کتابخانه است. کد پیگیری فقط در صورت نمایش در رکورد پر می‌شود. [نمونهٔ فیپا](https://opac.nlai.ir/opac-prod/bibliographic/10288541) · [راهنمای کتابخانه](https://opac.nlai.ir/opac-prod/search/bibliographicSimpleSearch.do?command=isoOnlineHelp)

`export_books` یک انتخاب می‌گیرد. `records` جزئیات شناسه‌ها را می‌خواند. `search` به‌صورت پیش‌فرض نمای خلاصه را می‌گیرد و با `include_details: true` حداکثر ۱۵ رکورد نخست را کامل می‌کند. Excel برگه‌های `Books` و `Coverage` دارد. JSON همهٔ فیلدهای دریافت‌شده را همراه پوشش نگه می‌دارد. CSV ستون‌های برگهٔ کتاب‌ها را می‌گیرد و گزارش پوشش در پاسخ ابزار می‌آید. برای عملیات گروهی در کلاینت زمان انتظار ۱۲۰ ثانیه تنظیم کنید.

تمام داده‌های شبکه از صفحات عمومی OPAC و دریافت رسمی UNIMARC می‌آیند. زمان دریافت UTC و پیوند منبع در خروجی آمده است. خطای اتصال یا چیدمان با وضعیت مستقل گزارش می‌شود. یک صفر صریح فقط پاسخ فهرست به همان درخواست است. درخواست‌ها در هر فرایند سریالی و با حداقل ۳۵۰ میلی‌ثانیه فاصله‌اند. حافظهٔ موقت جزئیات و گزینه‌ها ۱۲۰ ثانیه است.

# FutureTools MCP

سرور MCP رایگان با **۱۵ ابزار** برای دریافت **زنده** از [FutureTools](https://futuretools.io/tools): جست‌وجو و فیلتر، دسته‌بندی‌ها، جزئیات، مقایسه، ابزارهای مشابه و فایل واقعی Excel، CSV و JSON. اتصال `stdio` و `Streamable HTTP` پشتیبانی می‌شود.

**بدون کلید API، حساب کاربری، اشتراک، پراکسی پولی، مرورگر یا API مدل هوش مصنوعی کار می‌کند.** اجرای محلی رایگان و مجوز کد MIT است. قیمت ابزارهای معرفی‌شده از برچسب خود سایت گرفته می‌شود؛ رایگان بودن این MCP به معنی رایگان بودن تمام محصولات فهرست‌شده نیست.

این پروژه مستقل و غیررسمی است و وابسته یا مورد تأیید FutureTools یا Matt Wolfe نیست. دادهٔ اصلی در زمان درخواست از صفحه‌های عمومی سایت خوانده می‌شود؛ فایل دادهٔ دستی پیش‌نیاز نیست. cache کوتاه‌مدتِ دو دقیقه‌ای با زمان دریافت مشخص است.

## نصب

پیش‌نیاز: **Node.js 24** و دسترسی اینترنت به `futuretools.io`.

```sh
git clone https://github.com/Hhhkarimi/Hossein-Karimi-AI-Library.git
cd Hossein-Karimi-AI-Library/mcp/futuretools-mcp
npm ci --ignore-scripts
npm run build
npm test
```

در PowerShell، در صورت محدودیت `npm.ps1` از `npm.cmd` استفاده کنید. کتابخانه‌های لازم آزادند؛ سرویس پولی لازم نیست. اگر میزبانی ابری انتخاب کنید، هزینهٔ زیرساخت تابع میزبان شماست؛ اجرای محلی به آن نیاز ندارد.

## اتصال به کلاینت MCP

تنظیم `stdio`، بدون کلید:

```json
{
  "mcpServers": {
    "futuretools": {
      "command": "node",
      "args": ["C:/path/to/Hossein-Karimi-AI-Library/mcp/futuretools-mcp/dist/stdio.js"],
      "env": {"FUTURETOOLS_EXPORT_DIR": "C:/path/to/futuretools-exports"}
    }
  }
}
```

مسیرها را با مسیر مطلق دستگاه خود جایگزین کنید. در Linux/macOS نیز مسیر مطلق همان سیستم را وارد کنید. در تنظیمات کلاینت، `node` را مستقیم اجرا کنید؛ stdout سرور فقط پیام‌های پروتکل است. پس از افزودن یا ارتقا، اتصال MCP را restart کنید. نمونه‌ها در [examples](examples/) قرار دارند.

برای HTTP محلی:

```sh
npm run start:http
```

نشانی: `http://127.0.0.1:8792/mcp`. مسیر `/health` وضعیت برنامه را نشان می‌دهد. فایل `.env.example` فقط قالب تنظیمات است و خودکار بارگذاری نمی‌شود؛ محیط یا گزینهٔ Node یعنی `--env-file` را استفاده کنید.

## جست‌وجو و فیلتر

```json
{"name":"search_tools","arguments":{"query":"research","filters":["free"],"sort":"popular","page":1}}
```

ورودی جست‌وجو به نام `search` در URL عمومی سایت ارسال می‌شود. پارامترهای `categories`، `filters`، `sort` و `page` همان مسیرهای دیده‌شده در رابط سایت هستند. حالت اعمال‌شده از دادهٔ عمومی صفحه با ورودی تطبیق داده می‌شود؛ اگر سایت فیلتر یا صفحه را نادیده بگیرد، خروجی به‌عنوان نتیجهٔ صحیح ارائه نمی‌شود.

هر صفحه فعلاً حداکثر **۲۴ ابزار** دارد. برای ادامه از `next_page` استفاده کنید. `total_results` تعداد اعلام‌شده برای همان query است؛ `returned` اندازهٔ پاسخ فعلی. پاسخ یک صفحه به معنی کل فهرست نیست. ترکیب فیلترها تابع منطق خود سایت است؛ معنای AND/OR اضافی ساخته نمی‌شود.

فیلترها: `free`، `freemium`، `paid`، `open_source` و `matts_picks`. مرتب‌سازی: `newest`، `oldest`، `popular`، `popular_30d` و `name`. شناسهٔ دسته را از `list_categories` بگیرید. برای درخواست فارسی، دستیار میزبان می‌تواند عبارت جست‌وجو را به انگلیسی تبدیل کند؛ خود این سرور مترجم یا مدل پولی ندارد.

## فایل Excel

```json
{"name":"export_tools","arguments":{"search":{"query":"research","filters":["free"],"sort":"popular"},"format":"xlsx","max_pages":2}}
```

یا:

```json
{"name":"export_tools","arguments":{"tools":["claude","chatgpt-openai"],"format":"xlsx"}}
```

دقیقاً یکی از `search` یا `tools` را بدهید. خروجی واقعی `.xlsx` دو برگه دارد: `Tools` برای اطلاعات و `Coverage` برای منبع، زمان، محدوده و خطاهای جزئی. ستون‌ها شامل نام، توضیح، قیمت، دسته، رأی‌ها، منتخب بودن، API، متن‌باز بودن، لینک سازنده و منبع‌اند. فیلد گزارش‌نشده خالی می‌ماند و صفر واقعی حفظ می‌شود.

- در `stdio` فایل در `FUTURETOOLS_EXPORT_DIR` ذخیره می‌شود؛ پیش‌فرض `exports/` نسبت به پوشهٔ کاری فرایند است. مسیر مطلق `local_path` و `file_uri` برمی‌گردد. فایل تا حذف دستی باقی می‌ماند.
- در HTTP، `download_url` فایل را به صورت attachment تحویل می‌دهد. اگر `MCP_TOKEN` تنظیم باشد، دانلود نیز به همان Bearer token نیاز دارد.
- هر دو اتصال فایل را به صورت `resource_link` و از طریق `resources/read` با blob استاندارد MCP ارائه می‌کنند. میزبان باید لینک یا مسیر برگشتی را به کاربر نشان دهد؛ نمایش پیوست در همهٔ کلاینت‌ها یکسان نیست.

سقف خروجی جست‌وجو ۵ صفحه (حداکثر ۱۲۰ کارت) یا ۱۰ ابزار با شناسه است. `include_details=true` برای غنی‌سازی کارت‌ها درخواست جزئیات می‌فرستد و در سقف زمانی متوقف می‌شود. `selection_complete` کامل بودن محدودهٔ درخواستی و `entire_query_complete` کامل بودن تمام نتایج query را جدا نشان می‌دهند. در صورت خطای صفحهٔ بعد، دادهٔ موفق قبلی حفظ و خروجی ناقص صریح گزارش می‌شود. زمان انتظار کلاینت برای خروجی گروهی را ۱۲۰ ثانیه قرار دهید.

فایل‌های حافظه‌ای حداکثر یک ساعت، ۱۰ فایل و مجموعاً ۳۲ مگابایت نگه داشته می‌شوند؛ هر فایل حداکثر ۸ مگابایت است. با restart یا eviction باید فایل را دوباره تولید کنید.

## دقت و حدود داده

منبع تمام دادهٔ شبکه، صفحات عمومی FutureTools است. `source_url`، `fetched_at`، `cached` و `cache_expires_at` زمان و منبع هر پاسخ را نشان می‌دهند. دادهٔ صفحه به‌عنوان دادهٔ خارجی تلقی می‌شود و هیچ script آن اجرا نمی‌شود. دادهٔ عمومی render صرفاً با JSON parse می‌شود؛ API خصوصی یا دادهٔ حساب کاربری خوانده نمی‌شود.

قیمت و مشخصات، گفتهٔ فهرست هستند و تأیید مستقلِ شرایط فعلی فروشنده محسوب نمی‌شوند. `upvotes` رأی کاربران است، نه امتیاز کیفیت؛ در ترتیب ۳۰روزه، عدد رأی گزارش‌شده ممکن است کل دوره باشد. `find_alternatives` بر پایهٔ دستهٔ مشترک در یک صفحه است، نه فهرست رسمی جایگزین‌ها یا رتبه‌بندی جهانی. متن و لینک دستهٔ ترکیبیِ صفحهٔ جزئیات بدون حدسِ دسته‌های کوچک‌تر حفظ می‌شود.

خطای اتصال، ۴۰۳، چالش دسترسی، فیلد گزارش‌نشده و نبودن واقعی نتیجه یکی نیستند. خطاها `data_absence_confirmed=false` دارند. نتیجهٔ معتبر صفر فقط دربارهٔ همان query و همان زمان است. تغییر چیدمان یا عدم تطابق دادهٔ ساختاری با کارت‌های قابل‌مشاهده با خطای روشن گزارش می‌شود. دسترسی آیندهٔ یک سایت عمومی تضمین دائمی ندارد.

## آزمون و بررسی زنده

```sh
npm test
npm run verify:live
```

آزمون‌های خودکار از دادهٔ مصنوعی استفاده می‌کنند و به سایت درخواست نمی‌فرستند. آزمون زنده یک HTTP listener واقعی و کلاینت رسمی MCP ایجاد می‌کند، هر ۱۵ ابزار را فراخوانی می‌کند، فایل Excel از دادهٔ واقعی می‌سازد، آن را دانلود و بازخوانی می‌کند و تطابق `resources/read` را می‌سنجد. برای ذخیرهٔ گزارش، متغیر `VERIFY_REPORT` را روی مسیر فایل خود تنظیم کنید.

[گزارش بررسی](docs/VERIFICATION.md) و [منابع](docs/SOURCES.md) همراه پروژه‌اند. این پروژه یک endpoint ابری عمومی ایجاد نکرده است؛ انتشار گیت‌هاب، انتشار کد است.

## استقرار HTTP

پیش‌فرض فقط loopback است. برای میزبانی دور، `HOST` غیرمحلی، `MCP_TOKEN` حداقل ۲۴ کاراکتری و `PUBLIC_URL` با origin از نوع HTTPS تنظیم کنید. TLS در reverse proxy خاتمه یابد و Host عمومی حفظ شود. `Authorization: Bearer ...` را به کلاینت بدهید. توکن سرور، کلید سایت FutureTools نیست. کاربران یک سرور مشترک به همان خروجی‌های مجاز آن سرور دسترسی دارند؛ جداسازی چندمستأجری پیاده نشده است.

```sh
docker build -t futuretools-mcp .
```

این image به مرورگر نیاز ندارد. ساخت Docker در محیط تحویل آزموده نشده است. برای اجرای محلی Docker لازم نیست.

## رفتار فنی

فقط GET روی `/tools` و `/tools/slug` در origin ثابت `https://futuretools.io` انجام می‌شود. مسیرهای `/api`، `/go`، `/auth`، `/admin` و وب‌سایت فروشندگان فراخوانی نمی‌شوند. [robots.txt](https://futuretools.io/robots.txt) در بررسی اولیه، خواندن صفحه‌های عمومی را مجاز و همین مسیرها را ممنوع اعلام کرد.

در هر فرایند یک خواندن upstream هم‌زمان، فاصلهٔ شروع ۶۰۰ میلی‌ثانیه، timeout دوازده‌ثانیه‌ای شامل بدنه، صف حداکثر ۱۶ درخواست متمایز، بدنهٔ حداکثر ۲ مگابایت و cache حداکثر ۴۰ صفحه/۱۶ مگابایت وجود دارد. ۴۲۹ cooldown ایجاد می‌کند و retry خودکار ندارد. Redirect فقط به همین صفحه‌های عمومیِ origin ثابت و حداکثر دو جابه‌جایی پذیرفته می‌شود. بدنهٔ درخواست MCP حداکثر ۶۴ کیلوبایت است. کلید، cookie یا اطلاعات ورود ارسال نمی‌شود.

مجوز MIT برای کد است؛ حقوق محتوای سایت با دارندهٔ آن باقی می‌ماند.

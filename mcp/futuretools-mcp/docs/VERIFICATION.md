# گزارش بررسی نسخهٔ 0.1.0

تاریخ بررسی: **۲۰۲۶/۱۰/۲۶، Asia/Tehran**. محیط محلی: Windows و Node.js 24.18.0.

| بررسی | نتیجه |
|---|---|
| TypeScript strict build | موفق |
| آزمون‌های خودکار | ۴۲ موفق، صفر شکست، صفر مورد اجرا نشده |
| کلاینت رسمی MCP روی Streamable HTTP | هر ۱۵ ابزار با دادهٔ مصنوعی و سپس دادهٔ واقعی موفق |
| stdio با نسخهٔ پروتکل 2025-11-25 | initialize، فهرست ۱۵ ابزار و فراخوانی موفق با دادهٔ مصنوعی |
| HTTP listener واقعی | کنترل Host، Origin، Bearer token و سقف بدنه آزموده شد |
| دریافت زندهٔ فهرست، جست‌وجو، دسته‌ها و صفحهٔ دوم | موفق، بدون کلید، حساب، مرورگر یا واسط پولی |
| دسته‌بندی زنده | ۲۹ دستهٔ گزارش‌شده در همان اجرا |
| جزئیات واقعی و مقایسه | Claude و ChatGPT از صفحات FutureTools دریافت شدند |
| فیلترهای رایگان، متن‌باز، منتخب و محبوب ۳۰روزه | از طریق ابزارهای MCP اجرا و حالت اعمال‌شده تطبیق داده شد |
| دادهٔ واقعی → فایل Excel | ۲۴ نتیجهٔ جست‌وجوی زنده در فایل XLSX واقعی |
| تحویل فایل | دانلود HTTP و resources/read بایت‌های یکسان دادند؛ فایل با ExcelJS بازخوانی شد |
| کامل بودن کل query در خروجی نمونه | false؛ فقط یک صفحه دریافت شد و به‌صورت ناقص نسبت به کل query گزارش شد |
| خطا، timeout، ۴۲۹، تغییر ساختار و پاسخ نامعتبر | آزموده؛ به نتیجهٔ خالی یا دادهٔ ساختگی تبدیل نمی‌شوند |
| npm install/audit در ساخت محلی | صفر آسیب‌پذیری گزارش‌شده پس از override وابستگی uuid |
| ساخت image Docker و استقرار عمومی | انجام نشده؛ برای اجرای محلی لازم نیست |

[گزارش آزمون‌های مصنوعی](verification/unit-tests.xml) و [گزارش دریافت زنده](verification/live.json).

در اجرای زندهٔ ثبت‌شده، تمام ابزارها از طریق کلاینت رسمی و یک HTTP listener واقعی فراخوانی شدند. زمان‌های دقیق به UTC در فایل JSON هستند. آزمون زندهٔ نهایی از 20:22:11 تا 20:22:21 UTC روز ۲۰۲۶/۱۰/۲۶ ثبت شد. دانلود موفق فایل، تطابق بایت‌ها با منبع MCP و تطابق اولین سلول نام با اولین نتیجهٔ زنده سنجیده شد. دادهٔ کامل سایت در مخزن کپی نشده است.

آزمون‌های خودکار از fixtureهای مصنوعی استفاده می‌کنند و به سایت درخواست ندارند. گزارش زنده تأیید همان درخواست‌ها و همان زمان است؛ پایداری دائمی چیدمان سایت یا صحت مستقل تمام ادعاهای فروشندگان را تضمین نمی‌کند. CI نیز همین آزمون‌های بدون شبکه را پس از هر تغییر پروژه اجرا می‌کند.

برای بازتولید: `npm ci --ignore-scripts`، `npm test` و سپس `npm run verify:live`. اجرای آخر به سایت عمومی درخواست واقعی می‌فرستد. `VERIFY_REPORT` مسیر فایل گزارش اختیاری است.

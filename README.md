# کتابخانه پرامپت‌ها و اسکیل‌های هوش مصنوعی

این مخزن مجموعه‌ای ساختاریافته از پرامپت‌ها، اسکیل‌ها، سرورهای MCP، گردش‌کارها و نمونه‌های قابل استفاده مجدد برای ابزارها و مدل‌های هوش مصنوعی است.

## بخش‌های اصلی

### پرامپت‌ها

پرامپت‌ها بر اساس کاربرد دسته‌بندی شده‌اند:

- تولید تصویر
- نویسندگی و تولید محتوا
- برنامه‌نویسی
- تحقیق و تحلیل
- ایجنت‌ها و گردش‌کارهای چندمرحله‌ای

مسیر پرامپت‌ها:

[`prompts/`](./prompts/)

### اسکیل‌ها

اسکیل‌ها شامل دستورالعمل‌های کامل، فایل‌های نمونه، اسکریپت‌ها و منابع موردنیاز برای انجام وظایف مشخص هستند.

مسیر اسکیل‌ها:

[`skills/`](./skills/)

### سرورهای MCP

سرورهای MCP ابزارها و منابع بیرونی را به کلاینت‌های سازگار با Model Context Protocol متصل می‌کنند.

مسیر سرورها:

[`mcp/`](./mcp/)

### قالب‌ها

برای ساخت پرامپت یا اسکیل جدید، از قالب‌های آماده استفاده کنید:

[`templates/`](./templates/)

## ساختار مخزن

```text
prompts/   پرامپت‌های مستقل و قابل استفاده مجدد
skills/    اسکیل‌ها و گردش‌کارهای کامل
mcp/       سرورهای MCP و راهنمای اتصال
templates/ قالب استاندارد ساخت پرامپت و اسکیل
examples/  ورودی‌ها و خروجی‌های نمونه
docs/      مستندات و راهنماها
```

## شیوه نام‌گذاری

نام پوشه‌ها و فایل‌ها با حروف انگلیسی کوچک و خط تیره نوشته می‌شوند:

```text
persian-calligraphy
image-generation
prompt-optimizer
```

برای نام فایل‌ها از نام‌های زیر استفاده می‌شود:

```text
PROMPT.md
SKILL.md
README.md
examples.md
```

## امنیت

هیچ‌گاه اطلاعات زیر را داخل مخزن قرار ندهید:

- API Key
- Access Token
- رمز عبور
- اطلاعات خصوصی
- کلیدهای سرویس‌های ابری
- فایل‌های دارای اطلاعات محرمانه

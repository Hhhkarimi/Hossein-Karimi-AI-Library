# آزمون‌های لغزش

در هر تحویل، موردهای مرتبط را روی متنِ نهایی بررسی کن. این‌ها معیارهای ابطال‌اند، نه نمونه‌های شعر مطلوب.

| وضعیت | حکم لازم |
|---|---|
| چهار سطر با قافیهٔ AABA در وزن دوبیتی | به اسم رباعی نپذیر؛ وزن خانواده لازم است. |
| R01 در یک مصراع و R04 در دیگری | فقط به سبب متفاوت بودن ارکان رد نکن؛ هر دو می‌توانند عضو خانواده باشند. |
| درخواستِ صریحِ یک صورت دقیق، سپس مخلوط کردن R01 و R04 | قید کاربر رعایت نشده؛ به همان صورت بازنویسی کن. |
| مصراع سومِ نامقفّا ولی بی‌وزن | رد؛ آزادی قافیه، آزادی وزن نیست. |
| هر چهار پایان هم‌قافیه | AAAA معتبر است؛ مگر AABA صریح خواسته شده باشد. |
| «دست» در میانهٔ مصراع پیش از صامت | `dast` کشیده است؛ آن را بلندِ ساده نگیر. |
| همان «دست» در پایان | یک جایگاه بلند پر می‌کند؛ واحد کوتاهِ اضافه نگذار. |
| «دستِ من» | دوباره هجابندی کن: `das / te / man`؛ کمیتِ واژهٔ تنها را منتقل نکن. |
| «جان» و «جانِ من» | اولی معمولاً بلند؛ دومی `jā / ne / man`؛ حذفِ نون را به آغاز هجای تازه تعمیم نده. |
| «نه» در آخر مصراع و «نه» در میانه | اختیار پایان را فقط در پایان اعمال کن. |
| حذف کسرهٔ «دلِ من» یا یای «خانهٔ من» | رد؛ خوانشِ واقعی هجاهای اضافه دارد. |
| گرفتنِ ویرگول به‌عنوان پایانِ عروضی | رد؛ نشانهٔ مکث هجا را حذف یا بلند نمی‌کند. |
| برچسبِ «مفعول مفاعیل…» برای کل شعر در گنجور | صورتِ تک‌مصراع را از تقطیع بگیر، نه برچسب عمومی. |
| K در میانه، حذفِ u اضافی برای تطبیق | رد؛ کشیدگی را کامل حساب کن. |
| گرفتنِ K به‌عنوان دو هجای واقعی با واکهٔ ساختگی | رد؛ دو جایگاهِ کمّی با دو هجای ملفوظ فرق دارد. |
| انتخابِ کمیت از روی وزنِ مطلوب | رد؛ اول خوانش و کمیت، سپس تطبیق. |
| دو گذر با کمیتِ یکسان اما هجاهای متفاوت | در دفترِ یک خوانش، توافق کامل ثبت نشده؛ اختلافِ خوانش را بررسی کن. |
| ابزارِ سبز با دادهٔ آواییِ نادرست | تأیید وزن نیست؛ داده را با متن و تلفظ بسنج. |
| سبز بودن دفتر نسخهٔ قبلی پس از تعویض یک واژه | رد؛ دفترِ نسخهٔ جدید لازم است. |
| اختلافِ خوانش اول و دوم | وضعیت نامطمئن؛ دوباره بررسی یا بازنویسی کن. |
| سه پایان با «است» و بدون قافیهٔ پیش از آن | رد؛ ردیف جای قافیه نیست. |
| جفت «سرد / مُرد» فقط به علت «رد» | رد؛ واکه‌ها همسان نیستند. |
| نحوِ طبیعی فقط با چند مکثِ اجباری | بازنویسیِ جمله؛ علامت‌گذاری درمان نحو نیست. |
| سه مصراعِ مستقل و یک شعارِ پایانی | وزن کافی نیست؛ مسیر معنایی و کشف را بازسازی کن. |
| بازنویسیِ شعرِ شاهد با تعویض چند اسم | تولیدِ تازه محسوب نکن؛ تصویر و کشف مستقل بساز. |

## سناریوهای استفاده

1. «یک رباعی دربارهٔ جای خالیِ کسی پشت میز، با زبان امروز و بدون توضیح بنویس.» چهار مصراع طبیعی، سه قافیهٔ درست، همهٔ مصراع‌ها تأییدشده؛ فقط شعر در پاسخ.
2. «با قافیهٔ باران/پنهان/انسان و ردیفِ مانده است رباعی بساز.» قافیه را پیش از ردیف و وزن را با ردیفِ کامل بسنج؛ اگر معنا تحمیلی شد پایان‌های طبیعی‌تر پیشنهاد کن.
3. «این چهار سطر را بدون تغییر معنا موزون کن.» متنِ کاربر را شاهدِ سلامت خودش نگیر؛ محلِ خطا، کمترین تغییر و دفترِ تازه لازم است.
4. «رباعی بر مفاعیلن مفاعیلن فعولن بنویس.» تعارض را توضیح بده؛ وزنِ دوبیتی را با نام رباعی تحویل نده.
5. «فقط با قافیه تضمین کن وزن درست است.» خواستهٔ قالب خروجی را رعایت کن، اما تأیید فنی را از قافیه نتیجه نگیر.

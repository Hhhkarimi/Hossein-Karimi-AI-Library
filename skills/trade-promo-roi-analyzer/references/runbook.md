# اجرای قابل بازتولید

## محیط
Python 3.10+ و کتابخانه‌های scripts/requirements.txt. موتور به شبکه، API پولی یا statsmodels وابسته نیست؛ OLS با numpy.linalg.lstsq اجرا می‌شود. در Codex مسیر runtime موجود را کشف کن؛ وابستگی را فقط اگر لازم و مجاز است نصب کن. در Code Interpreter، بسته را باز کن و script را از مسیر محلی فراخوانی کن. نصب خودکار skill در محیطی که مفهوم نصب ندارد لازم نیست.

## ترتیب اجرا
۱. فایل واقعی را بررسی، پرسش‌های ضروری را بپرس و قرارداد داده را استاندارد کن.
۲. قالب assets/config.template.json و CSVها را در پوشه مستقل کار کپی و تکمیل کن. همه مسیرها نسبت به config هستند.
قالب جایگزین assets/input-template.xlsx سه شیت داده خالی دارد؛ اطلاعات از ردیف ۲ وارد می‌شود. فایل assets/analysis-contract.template.json فرم قرارداد تحلیل است و به analyze.py داده نمی‌شود.
۳. در حالت مالی cost_coverage_confirmed فقط پس از تأیید پوشش هزینه true می‌شود. بدون آن financial_mode=false بگذار؛ four financial columns و costs لازم نیستند.
۴. اجرا:
    python scripts/analyze.py --config path/to/config.json --output path/to/new-run
۵. فایل HTML و جمع‌های CSV/manifest را ببین، پرچم‌ها را بررسی و گزارش تحلیلگر را تکمیل کن.

یک workbook: در sales، campaigns و costs مقدار path یکسان و sheet به‌ترتیب نام شیت شود. column_map از استاندارد به ستون واقعی است، مثلاً {"units":"مقدار خالص","series_id":"شناسه سری"}. ابتدا معنای ستون تأیید شود.

تنظیمات پیشنهادی اولیه: daily، bootstrap_samples=500، block_length=7، seed=42؛ هفتگی/ماهانه block=3. این تنظیمات مدرک کفایت نیستند. طول بلوک، فصل، طول افق و خطای اعتبارسنجی را با داده بررسی کن. بازه‌گیری نهایی حساس به نمونه می‌تواند به تکرار بیشتر نیاز داشته باشد.

## دمو و کنترل
    python scripts/make_demo.py --output path/to/new-demo
    python scripts/analyze.py --config path/to/new-demo/config.json --output path/to/new-demo-run
    python -m unittest discover -s scripts -p "test_*.py" -v

داده ساختگی شامل سه سری مستقل است: سودآور، افزایش حجم زیان‌ده و امضای جابه‌جایی زمانی. known_synthetic_truth.csv فقط برای ارزیابی نمونه است و به موتور داده نمی‌شود. نمونه از داده خصوصی یا بازار واقعی استخراج نشده است.

## حساسیت
    python scripts/sensitivity.py --run path/to/run --baseline-factors 0.9 1 1.1 --extra-costs 0 1000 --output path/to/scenarios.csv

اعداد بالا فقط مثال‌اند. سناریو فرض می‌کند حجم خلاف‌واقع و مشارکت خلاف‌واقع در یک نسبت مقیاس می‌شوند و هزینه اضافی هم در صورت و هم در مخرج وارد می‌شود. این خروجی بازه اطمینان نیست. برای حاشیه، قیمت، پس‌دوره یا روش خط پایه، config/فایل استاندارد را در کپی جدا تغییر و موتور را مجدد اجرا کن؛ منشأ فرض را ثبت کن.

## توقف‌های عمدی
دوره مفقود، تکرار کلید، مقدار غیرعددی/نامتناهی، date مبهم، flag نامعلوم، هزینه یتیم/تکراری، پوشش هزینه تأییدنشده، افق ناقص، هم‌پوشانی اثر، تاریخچه ناکافی یا رتبه ناقص، خطای تصمیم‌پذیر می‌دهند. با صفرگذاری، کوتاه‌کردن پس‌دوره بدون افشا یا حذف کمپین خطا را پنهان نکن. داده/دامنه را روشن کن یا تحلیل سفارشی مناسب بساز.

خروجی باید پوشه جدید/خالی باشد. برای اجرای بعدی پوشه جدید انتخاب کن؛ موتور اجرای قبل را بازنویسی نمی‌کند. CSV خروجی، متن‌های آغازشونده با علائم فرمول را هنگام export خنثی می‌کند؛ شناسه اصلی در manifest و ورودی محفوظ است.

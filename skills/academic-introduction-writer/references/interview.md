# Adaptive interview

Ask a small number of high-value questions, not the full bank below. Read attachments before requesting summaries. If files are inaccessible, ask for relevant text. Introduction writing rarely needs identifiable participant information or raw data.

For a title-only Persian request, a suitable opening is:

> برای شروع سه چیز را بفرمایید: پرسش اصلی مقاله چیست؟ پژوهش را با چه روشی انجام داده‌اید یا قرار است انجام دهید؟ متن مقدمه فارسی باشد یا انگلیسی؟ اگر چکیده آماده دارید، همان را بفرستید.

## Question bank

| Area | Useful missing information |
|---|---|
| Task | Draft, revision, critique, adaptation, translation; scope to preserve |
| Topic | Discipline, problem, constructs, boundaries, terminology |
| Research | Question, design, population/unit, context, period; completed/planned |
| Contribution | Difference from nearest work and why it matters |
| Literature | Closest papers, competing explanations, conflicting evidence |
| Sources | Full texts, bibliography, DOI/URLs, RIS/BibTeX; access limits |
| Venue | Journal, author instructions, readership, article format |
| Output | Language, English variety, length, reference style/variant, format |
| Preferences | Concision, explanatory depth, paragraph workflow, author voice |

Ask about theory and hypotheses only when relevant. For theoretical work ask for thesis/reasoning; for a protocol ask planned aims; for a review ask type, scope and nearest reviews.

## Brief to maintain

```text
Task and scope:
Topic and discipline:
Article type / study stage:
Problem and question:
Method / population / context:
Proposed contribution and its verification status:
Closest work:
Journal / audience:
Manuscript language / interview language:
Length / citation style and variant:
Evidence and access:
Author preferences:
Open scientific questions:
Provisional assumptions:
```

Keep confirmed fields when resuming. Latest explicit preference replaces older preference. Conflicting factual accounts need clarification. Record the resolution.

## Readiness

- Minimum facts available: begin; evidence absent: provisional only.
- Complete brief and sources: proceed directly; do not force intake.
- "Write now": draft what is possible, mark missing essentials, list remaining needs.
- No study yet: help develop questions and contribution; label proposals as proposals.
- "Choose for me": choose presentation defaults, not scientific facts.
- Two or three reasonable options: recommend one with a short reason.

No fixed interview-round count. Prioritize scientific validity, evidence, then presentation. Allow the author to answer in prose, a file or a completed form. Do not re-ask unanswered optional preferences indefinitely.

For selected-passage revisions, preserve material outside the selection. Explain substantive claim changes instead of silently changing the author's position.

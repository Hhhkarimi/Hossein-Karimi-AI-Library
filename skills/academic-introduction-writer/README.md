# نویسندهٔ تعاملی مقدمهٔ مقاله

نسخهٔ ۱٫۰٫۰ — ویژهٔ ChatGPT و Codex؛ گفت‌وگو و خروجی فارسی یا انگلیسی.

[دریافت ZIP نسخهٔ ۱٫۰٫۰](https://github.com/Hhhkarimi/Hossein-Karimi-AI-Library/raw/refs/heads/main/skills/academic-introduction-writer/dist/academic-introduction-writer-1.0.0.zip)

این مهارت با نویسنده همکاری می‌کند تا از اطلاعات پراکنده به مقدمه‌ای منسجم و مستند برسد. ابتدا اطلاعات موجود را می‌خواند و هر نوبت حداکثر سه سؤال می‌پرسد. سپس منطق مقاله، جایگاه آن در پیشینه، نقشهٔ پاراگراف‌ها، متن و ارجاع‌ها را می‌سازد و بازبینی می‌کند.

## شروع سریع

در Codex:

```text
$academic-introduction-writer
می‌خواهم مقدمه مقاله‌ام را با همکاری تو بنویسم. از اطلاعات لازم شروع کن.
```

با چکیدهٔ آماده:

```text
$academic-introduction-writer
چکیده و منابع پیوست را بخوان. اطلاعات موجود را دوباره نپرس.
مقدمه انگلیسی، حدود ۸۰۰ کلمه و ارجاع APA 7 می‌خواهم.
```

در ChatGPT از انتخابگر @ نام مهارت را انتخاب کنید، اگر مهارت نصب شده است. بدون نصب، فایل [نسخهٔ یکپارچه](deployment/chatgpt-instructions.md) را ضمیمه کنید و بنویسید:

```text
فایل راهنما را بخوان و روش آن را در این گفت‌وگو اجرا کن.
برای نوشتن مقدمه با من مصاحبه کن؛ هر بار حداکثر سه سؤال.
```

## چه اطلاعاتی می‌گیرد؟

موضوع و رشته، نوع مقاله، مرحلهٔ پژوهش، مسئله و پرسش، روش و جامعه، سهم علمی، نزدیک‌ترین پژوهش‌ها، مجله، زبان، حجم، سبک ارجاع، منابع و ترجیحات نویسنده. همه را یکجا نمی‌پرسد. «نمی‌دانم» را می‌پذیرد و برای ترجیحات پیشنهاد می‌دهد.

## مسیر همکاری

۱. شناسنامهٔ مقاله ← ۲. بررسی شواهد و جایگاه ← ۳. طرح مقدمه ← ۴. نگارش ← ۵. ممیزی و اصلاح.

متن خروجی همراه منابع و یادداشتی کوتاه دربارهٔ تصمیم‌ها و موارد باز ارائه می‌شود. اگر شواهد ناقص باشد، برچسب پیش‌نویس موقت می‌گیرد. اطلاعات علمی مجهول با حدس تکمیل نمی‌شود.

## پوشش

- پژوهش کمی، کیفی و آمیخته؛ مرور نظام‌مند، دامنه‌ای و روایتی؛ روش، نظریه، گزارش مورد، تکرار و پروتکل؛
- ساختار قیفی، مسئله‌محور، شکاف‌محور، تناقض‌محور، نظریه‌محور یا روایی؛
- APA، Vancouver، IEEE، Chicago، MLA و نسخهٔ مشخص Harvard؛
- ساخت، بازبینی، کوتاه‌سازی، ترجمه و انطباق با مجله؛
- مقایسه با نزدیک‌ترین آثار، شواهد مخالف و کنترل ادعای نوآوری؛
- وضعیت مستقل دسترسی، هویت منبع و پشتیبانی از ادعا.

## نصب

پوشهٔ کامل `academic-introduction-writer` را در مسیر مهارت‌های محیط خود قرار دهید. طبق [مستندات OpenAI](https://learn.chatgpt.com/docs/build-skills)، مسیر پروژه در Codex برابر `.agents/skills/` و مسیر کاربر `.agents/skills/` در خانهٔ کاربر است. برخی نسخه‌های قدیمی مسیرهای دیگری دارند؛ از مسیر همان نسخه استفاده کنید. نصب هم‌زمان دو نسخهٔ هم‌نام لازم نیست.

برای نصب از GitHub با Skill Installer:

```text
$skill-installer
Install the skill from:
https://github.com/Hhhkarimi/Hossein-Karimi-AI-Library/tree/main/skills/academic-introduction-writer
```

برای ChatGPT دسکتاپ، در محیط دارای Skill Creator پوشه را به آن معرفی کنید. قابلیت نصب با سطح محصول و حساب فرق دارد. استفادهٔ فایل یکپارچه در چت یا پروژه، نصب دائمی مهارت نیست. این مخزن به دایرکتوری عمومی افزونه‌ها ارسال نشده است.

Python 3.10+ کافی است؛ اسکریپت‌ها کتابخانهٔ بیرونی نمی‌خواهند.

```text
python scripts/build_release.py --output-dir ../release
python scripts/validate_package.py
python scripts/test_package.py
```

فایل یکپارچه تولیدی است؛ ابتدا فایل‌های اصلی را ویرایش و سپس آن را بازتولید کنید. ساخت بسته زمان ثابت و SHA-256 دارد و نسخهٔ یکپارچه را پیش از ZIP می‌سازد. اجرای ساخت، فایل یکپارچهٔ موجود را بازنویسی می‌کند.

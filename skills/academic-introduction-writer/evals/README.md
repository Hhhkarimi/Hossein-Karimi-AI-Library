# Behavioral evaluation

Give an evaluator SKILL.md, referenced resources, a request and its raw artifacts. Run outside the delivery directory. Do not expose the expected checks until after the response. Score observable decisions, not wording. Store the actual response separately.

For each scenario report pass/partial/fail/not run, evidence and limitation. A question about sources is not proof of verification. A source-checked label requires actual checks. Structural validation is separate from behavioral evaluation. A few cases cannot establish reliability across disciplines.

Use scenarios.json as a case bank, not an automated test claim. For numeric cases supply a short draft with 3 sources, repeated citations and moved paragraphs. For source cases supply a known full text or abstract. Never use real confidential manuscripts in public evaluation artifacts.

# Content architecture

## Editorial compression ladder

Convert source paragraphs through these layers:

1. Claim / concept
2. One-line explanation
3. Proof/example if available
4. Slide-level takeaway

Only layers 1–3 usually appear on the slide. Keep nuance in the source notes/spec if it would overload the visual.

## Slide archetypes

### Cover
- Eyebrow label
- Hook/title
- Subtitle/promise
- Optional portrait
- Byline
- Slide indicator

### Two-card explainer
- Strong slide title
- Card A: icon + short heading + 2–3 bullets
- Card B: icon + short heading + 2–3 bullets

### One-big-idea
- One statement or number
- One supporting diagram/illustration
- 2–3 short explanatory lines

### Comparison
- A vs B or Before vs After
- Keep columns symmetric
- Max 4 rows

### Summary/CTA
- 3 takeaways or a compact framework
- CTA optional
- Optional portrait reappearance

## Density rule

If a slide needs a body font that looks small on a phone, the editorial compression is not finished.

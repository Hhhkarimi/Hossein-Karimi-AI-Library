# Failure modes and targeted repairs

| Failure | Observable signal | Repair and regression case |
|---|---|---|
| Criticism quota | Strong paper gets invented “major” weaknesses | Remove quotas, require anchor/consequence; T01 |
| Status/severity collapse | Clarification becomes confirmed fatal flaw | Restore independent axes, examine missing evidence; T10/T15 |
| Reporting/conduct collapse | Unreported blinding called proof none occurred | Use exact available-information wording; T07 |
| Discipline mismatch | Theory gets power demand or reflexive analysis gets compulsory coder kappa | Correct classification and route; T05/T06/T09 |
| Citation hallucination | Plausible DOI/quote with no opened evidence | Withdraw, log real dimension/scope; T08/T14 |
| Confidentiality bypass | Reads unknown/prohibited material because uploaded | Enforce pre-content gate, no evasion by anonymization; T11/T21 |
| Hidden exfiltration | Novel unpublished phrase sent as search query | Reassess destination permission, use permitted generic query; T17 |
| Extraction error | OCR mismatch promoted to confirmed author error | Compare original, downgrade/withdraw; T13 |
| Recommendation drift | Final decision uses merged/withdrawn finding | Recompute synthesis from surviving IDs and remediability; T15/T18 |
| Scope expansion | Mandatory unrelated dataset, trial or experiment | Tie each essential demand to actual claim; T04/T16 |
| Integrity overclaim | Similar figure or failed lookup labeled fraud | Describe indicator and alternatives, refer to human assessment; T08/T20 |
| Tool simulation | Claims code run or full list checked without logs | Correct scope statement, execute only permitted available check; T14/T19 |
| Context loss | Revised/long manuscript loses source version or unread status | Restore checkpoint and revalidate anchors; T18 |
| Knowledge drift | Custom GPT bundles differ from source procedures | Regenerate with build_knowledge.py, validate stale bundles |
| False deployment claim | Local package pass presented as hosted GPT validation | Report target deployment as untested until actually configured and exercised |

Fix the instruction/source responsible for an observed failure, not every file. Regenerate derived Knowledge after changes. Record both the failure and corrected re-test rather than rewriting history as an initial pass.

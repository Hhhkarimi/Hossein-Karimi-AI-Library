# Scientific Peer Review Expert — SPRE

نسخهٔ ۱٫۰ — اسکیل ماژولار برای کمک به داوری علمیِ مستند، منصفانه و قابل‌ردیابی در رشته‌های گوناگون، با تعامل و گزارش فارسی و انگلیسی. توصیهٔ اسکیل مشورتی است؛ داور متخصص و سردبیر مسئول تصمیم و صحت گزارش‌اند.

## طراحی و بهبودها

SKILL.md مسیر اجرا را نگه می‌دارد؛ جزئیات فقط هنگام نیاز از ماژول‌ها خوانده می‌شوند. ورود مقاله پیش از بررسی محتوا، مجوز و محرمانگی را روشن می‌کند. دوازده مرحلهٔ علمی یک ثبت شواهد مشترک دارند تا محل نقد، مبنای علمی و ادعای متأثر از آن قابل پیگیری باشد.

شدت نقد از میزان اثبات آن مستقل است. نبود گزارش یک روش به معنی انجام‌نشدن آن نیست. کیفیت گزارش‌دهی با اعتبار روش و قطعیت مجموعهٔ شواهد یکی گرفته نمی‌شود. برای پژوهش کیفی، نظری و بین‌رشته‌ای معیار مناسب انتخاب می‌شود. در مقالهٔ قوی نقد اساسی اجباری وجود ندارد؛ در مقالهٔ ناقص توصیهٔ نهایی می‌تواند معلق بماند. رد مقاله نیازمند شواهد و توضیح اصلاح‌ناپذیری متناسب یا عدم تناسب مستند با مجله است.

راستی‌آزمایی منبع، وجود اثر و صحت مشخصات را از پشتیبانی واقعی ادعا جدا می‌کند. دامنهٔ جست‌وجو و موارد بررسی‌نشده گزارش می‌شود. دستور مخرب داخل مقاله اجرا نمی‌شود. برای نسخهٔ اصلاح‌شده شناسه‌های نقد حفظ می‌شوند. هیچ ابزار، جست‌وجو، محاسبه یا داوری انسان مستقلی شبیه‌سازی نمی‌شود.

## معماری و درخت فایل

درخت کامل نسخهٔ تحویلی در [FILE-TREE.txt](FILE-TREE.txt) تولید می‌شود. بخش‌ها:

| بخش | وظیفه |
|---|---|
| config | پیش‌فرض‌ها و تنظیمات هر نوبت داوری |
| workflows | ورود، طبقه‌بندی، مراحل، بررسی شواهد، تصمیم، کنترل کیفیت |
| references | اصول، روش، آمار، نوآوری، استانداردها، اخلاق، منابع |
| templates | نقد اساسی/جزئی، ثبت شواهد، جمع‌بندی تصمیم و گزارش |
| deployment | Instructions مستقل و چهار فایل Knowledge تولیدشده |
| tests | ۲۲ سناریوی رفتاری، معیار قبولی، خطاها، نمونه‌های مصنوعی، آزمون ابزارها |
| scripts | تولید Knowledge و اعتبارسنجی ساختار؛ بدون نیاز به API یا بستهٔ پایتون اضافی |
| agents | فرادادهٔ نمایشی Codex |

## حدود کاربرد

بدون داده، ابزار یا دسترسی لازم، صحت کد، تکرار کامل تحلیل، اصالت همهٔ تصاویر، نوآوری جامع یا محتوای منبعِ غیرقابل‌دسترسی تأیید نمی‌شود. هیچ تضمینی دربارهٔ پذیرش، نبود تخلف، امنیت محیط یا سازگاری با سیاست همهٔ مجلات وجود ندارد. مقالهٔ محرمانهٔ غیرمجاز پردازش نمی‌شود. پیش از ارسال گزارش، انسان باید شواهد و متن را بررسی کند.

Knowledge از منابع اصلی ساخته می‌شود؛ تغییرات را در فایل‌های اصلی انجام دهید و سپس ابزار تولید را اجرا کنید. نتایج آزمون ساختار، آزمون ابزار و آزمون رفتار مدل جداگانه گزارش می‌شوند. آماده‌بودن فایل‌ها به معنی ساخته یا منتشرشدن یک GPT در حساب شما نیست.

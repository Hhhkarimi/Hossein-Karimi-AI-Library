# Manuscript Literature Review

Write prose the author can put into a manuscript. Use the author's contribution to choose the comparisons. Let the evidence determine what distinction, if any, survives those comparisons.

## Start with the author

Use the language of the conversation for intake. Reuse information already supplied. Ask the unanswered items together, in one short message.

- What is the working title?
- What does the paper contribute? One to three sentences are enough. If status is unclear and matters, ask which components are proposed, implemented, or evaluated.
- Would you like a detailed checkmark table comparing this paper with the closest studies?
- Which citation and reference style should I use? The default is APA 7th edition.

Honor an explicit journal style, output language, source restriction, or length. If the author accepts defaults, use APA 7 and omit the optional table unless requested. A title alone rarely establishes what the author did. Obtain the contribution before drafting a positioning claim. An abstract, journal name, and seed papers can help when available. They are optional.

## Find the evidence

1. **Route discovery.** Inspect the available tools, including deferred connectors. When Consensus is installed and usable, actually run its scholarly search. Fetch each selected record before citing it and inspect accessible full text where the claim needs it. Respect current connector requirements for attribution. If numbered source markers are required when reporting Consensus results, retain their mapping in a separate discovery note and use the author's chosen citation style in the manuscript.
2. **Handle availability.** If Consensus is absent, offer installation once, preferably alongside intake. Use the host's plugin suggestion flow if available. If the author declines or has already chosen search, proceed with academic and general web search. If the connector is present but returns an access, quota, or service error, use the available search routes and identify the actual limitation. If the user accepted installation, check for a callable tool after setup. A failed setup need not interrupt the review.
3. **Search across channels.** Even with Consensus, use a subject index, academic search, or a general web search when it adds coverage. Turn the title and contribution into separate queries for the problem, the mechanism or method, and the claimed advance. Include older names and competing labels. Use general search to find original articles on journal, proceedings, university, or repository pages. Treat search snippets as leads. If external retrieval is unavailable, work from sources supplied by the author, identify the coverage limit, and request source material if there is none.
4. **Recover the history.** Use a field review or a recent close comparator to follow references back to original formulations, methods, and decisive early studies. Verify the original work and what it introduced. Explain why a classic changed the question, the measurement, or the available method. An old publication date alone establishes none of these.
5. **Search through the present.** Run a date-bounded query through the actual search date, including current-year and online-first work. As a starting point, examine the last 24 months and adjust to the field's pace. Follow forward citations from key papers where possible. Seek direct precedents, null findings, and replications, including work that uses different terminology. Check whether a preprint has a published version. If the recent search yields little, report the dates and nearest relevant work.
6. **Test the proposed contribution.** Search each component independently and their combination. Compare the strongest competing study in terms of question, setting, method, evaluation, and result as applicable. If a predecessor already achieves the claimed advance, acknowledge it and narrow the distinction to what the author can substantiate. If the evidence supports only a replication, extension, or new context, describe that contribution on its own terms.

Keep a brief working record of the date, sources actually searched, queries, and coverage limits. For each study used, retain its verified identity, version, accessible evidence (abstract, full text, or supplement), and a locator for the claim it supports. Track overlapping datasets or reports before describing findings as independent. Cite original evidence for specific results and reviews for field-level synthesis. Check correction and retraction notices where relevant. Omit or qualify details beyond the accessible text.

## Write the section

Use these seven writing tasks as rhetorical moves. Headings and order should suit the manuscript.

| Task | What the reader should learn |
|---|---|
| Frame the relevant literature | Define the problem and its scope. Introduce the distinction that organizes the studies and explain its relevance to the paper's question. |
| Give a historical perspective | Connect verified turning points. Explain which earlier constraint or assumption each advance addressed. |
| Compare methodological approaches | Group studies by how they answer the question. Show how a consequential design choice changes the interpretation or limits comparison. |
| State what is currently known | Distinguish converging results, live disagreements, and underexamined conditions. Weight conclusions by study design, independence, and relevance. |
| Describe published work precisely | Name the researcher or study when attribution matters. Use verbs that fit the evidence, such as *proposed*, *observed*, *estimated*, or *replicated*. Put the citation beside the claim. |
| Introduce quotations selectively | Quote when exact language matters, such as a disputed definition. Introduce it with a signal phrase, verify the wording in the original, give a page or other valid locator, and explain the quoted distinction. Otherwise paraphrase. |
| Synthesize and position | Close major themes with the inference they support. End with the closest comparison, what remains unresolved within the reviewed scope, and the specific contribution the author describes. |

Build paragraphs around a shared question. For example, if two studies disagree, examine whether they used the same outcome, follow-up interval, and population before suggesting an explanation. Distinguish a demonstrated explanation from a plausible one. Avoid treating a difference in statistical significance as evidence that the two estimates differ. For conceptual work, compare definitions, assumptions, and scope conditions. For computational work, attend to datasets, baselines, and evaluation protocols.

## Deliver and verify

Return the manuscript section in the requested language and length, followed by the optional table and a complete reference list. For a requested table, read [the positioning matrix guide](references/positioning-matrix.md). Keep tool messages and search process out of the manuscript. Give the author a short separate note with the search date and any material coverage or verification limits.

Apply the chosen style to both in-text citations and references. In APA 7, use author–date citations, disambiguate same-author/same-year works, alphabetize the list, and present verified DOIs as DOI URLs. Use the appropriate reference format for the actual publication type. Reconcile citations in both prose and table with the reference list in both directions. Check names, dates, titles, venues, publication details and identifiers against the publisher or a reliable scholarly record. Supply only verified fields. Revisit the evidence behind quotations, numerical claims, novelty statements, and table cells. Describe proposed work in prospective language until the author supplies evidence of completion.

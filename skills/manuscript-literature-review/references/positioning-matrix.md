# Building a study-positioning matrix

The table should let a reader inspect the precise distinction claimed for the present paper. Include the closest overlap even when it weakens the author's initial claim. Add a foundational or recent study when it helps explain that distinction. Give one cited study per row and place the present study last.

## Design columns before assigning marks

Break the contribution into independently checkable criteria. For each criterion write a compact header, a one-sentence decision rule, and the evidence needed to mark it. Apply the same rule to every row. Include dimensions on which prior studies have strengths. Select only dimensions that matter to the question and separate criteria that could produce different answers.

For example, a study claiming transfer across clinical sites and calibration under temporal shift might need these separate columns:

| Column | Evidence that qualifies |
|---|---|
| Unseen hospital at test | At least one evaluation hospital contributed no development records. |
| Future-period test | Every test record in the specified evaluation follows the training cutoff. |
| Calibration slope | The study reports a calibration slope on the specified test set. |
| Calibration interval | The study reports an uncertainty interval for that slope. |
| Site-level results | The evaluation reports the outcome separately for each test hospital. |

These are examples for one contribution. Derive different columns for a theoretical paper, such as assumptions about observability, the specific proposition proved, and the boundary condition under which the proof holds. Split a wide matrix into labeled panels with identical row order. Avoid generic headings such as “advanced method,” “real data,” and “validation.”

## Code what the evidence shows

Use **✓** for a documented match and **✗** for a documented mismatch. Define both in the caption. Reserve an em dash **—** for unresolved or inapplicable cells, with a short note explaining each such cell. This preserves the binary comparison wherever the evidence permits it. A silent abstract does not justify a cross. An explicitly internal-only test can justify a cross for the unseen-hospital criterion. Check full text or supplements when available before leaving a cell unresolved.

Keep an evidence note for each decision, such as a Methods subsection, numbered table, proposition, or the author's manuscript passage. Put row-level locators in a final “Evidence” column or keyed notes below the table. Identify the source and relevant cells if a row draws on multiple locations. Distinguish missing reporting from nonapplicability in those notes.

Apply the same evidence threshold to the present study. When only a proposal is available, label the row “Present study (planned)” and explain in the caption that its ticks denote explicit design commitments. If the paper mixes planned and completed elements, use separate labeled rows or cell-specific status notes. A promise to run a benchmark cannot support a tick for a criterion requiring a reported result.

After the table, explain the most important overlap and the narrowest supported difference in one or two sentences. A column of crosses establishes a pattern among the studies compared. Claims about the entire field require a broader evidential basis.

# Reporting guidance by study design
These are editorial routing summaries, not complete checklists or certification. Consult the official current document when exact compliance is requested. All required data must come from the study.

| Design | Relevant guidance | Abstract-critical items |
|---|---|---|
| Randomized trial | CONSORT 2025; CONSORT for Abstracts | design, allocation groups, primary outcome, numbers analyzed, effect and precision, important harms, registration/funding if required |
| Observational study | STROBE | design, population, exposure/outcome, principal association, confounding and scope |
| Systematic review | PRISMA 2020 for Abstracts | objective, eligibility, sources and last search, risk of bias, synthesis method, included studies, principal results, limitations, interpretation, funding and registration if applicable |
| Scoping review | PRISMA-ScR | objective, eligibility, sources, charting, mapped evidence and gaps |
| Diagnostic accuracy | STARD for Abstracts | participants, index test, reference standard, design, accuracy estimates and uncertainty |
| Prediction model | TRIPOD+AI where applicable | population, target outcome, development/validation, discrimination/calibration or relevant measures, limitations |
| Qualitative | SRQR / COREQ where applicable; APA JARS-Qual | context, approach, sampling/material, analytic method, themes/interpretation, implications |
| Mixed methods | APA JARS-Mixed | rationale, components, integration and joint findings |
| Protocol | SPIRIT or PRISMA-P as appropriate | planned design and outcomes; no invented results |
| Animal preclinical | ARRIVE where applicable | organism/model, design, primary outcome, relevant experimental conditions |
| Case report | CARE | case presentation, intervention or assessment, outcome and lesson |

For reviews, distinguish number of records, reports, studies and participants. Never call a review systematic merely because it cites many papers. For machine learning, identify evaluation split or external validation only if reported; avoid treating training performance as generalization. For theoretical work, report the central argument, theorem or conceptual contribution rather than invented empirical outcomes.

Official starting points: https://www.equator-network.org/ ; https://www.prisma-statement.org/ ; https://www.consort-spirit.org/ ; https://apastyle.apa.org/jars ; https://www.strobe-statement.org/ ; https://www.tripod-statement.org/ ; https://arriveguidelines.org/ ; https://www.care-statement.org/ .

# Keyword selection rubric
Use internally; scores are editorial heuristics, not measured search demand.

1. Generate 12–20 candidates if supported by the manuscript; fewer for narrow topics. Include topic, specific constructs, method, domain and distinctive contribution. Check synonyms and official terminology.
2. Reject any candidate not directly supported by manuscript scope, any misleading trend association, and generic terms with no meaningful indexing function.
3. Rate remaining candidates from 0–4 on relevance R, disciplinary recognition D, plausible search intent S, specificity P and complementary coverage C (reassess C after each selection). Use R >= 3 as a gate. Optional ranking: (35R + 25D + 20S + 10P + 10C)/4. These weights are design preferences, not empirically calibrated.
4. Select 5–7 by default. Balance recognizable broader terms with distinctive multiword phrases, adding methods or populations only if central. Deduplicate acronyms/full forms unless separately useful and allowed by journal.
5. Verify controlled terms via the relevant vocabulary when possible: MeSH https://meshb.nlm.nih.gov/ ; AGROVOC https://agrovoc.fao.org/ ; ERIC https://eric.ed.gov/?ti=all . Do not claim a vocabulary match without verification.
6. If current interest is requested, use only authorized nonconfidential public topic queries; document source and date, distinguish observed frequency from citations or popularity. No automatic external calls in this skill. Do not expose raw scores by default.

Example: a study of satellite imagery for urban heat mapping may support Urban heat island; Land surface temperature; Remote sensing; Landsat; Urban vegetation. Reject Generative AI if not used. Never assume a listed example is evidence for a new article.

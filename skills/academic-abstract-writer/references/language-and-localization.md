# Language And Localization

## Detect and preserve language

- Determine the primary language from the substantive manuscript body, especially the introduction, methods, results, and discussion. Ignore references, imported quotations, isolated terms, bilingual titles, and incidental translated abstracts when identifying the dominant language.
- Write the abstract, headings, and keywords in that language, even when the user's request is written in another language. An English manuscript gets an English abstract; a Persian manuscript gets a Persian abstract; apply the same rule to all other languages.
- Explicitly requested output languages override automatic detection. If bilingual output is requested, provide a complete abstract and separate keywords for each language, maintaining factual equivalence.
- For genuinely mixed-language manuscripts, use the declared primary language or the language of the main body. Ask one focused question only if no defensible primary language can be established.
- Use the discipline's established terminology, idiomatic syntax, punctuation, spelling, and script conventions. Preserve proper names, model identifiers, standard symbols, units, and internationally recognized acronyms where necessary.
- For Persian, use standard formal academic Persian, consistent terminology, Persian orthography and punctuation, and appropriate half-spaces (نیم‌فاصله). Avoid literal English calques and unnecessary English glosses. Retain original identifiers and technical notation when translation would introduce ambiguity.
- Do not introduce untranslated English keywords into a non-English keyword list unless the terms are canonical identifiers, customary in the field, or explicitly requested. Do not add an unsolicited translated abstract.
